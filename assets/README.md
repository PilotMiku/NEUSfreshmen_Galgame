# 照片使用说明

原图保存在本地“图片”文件夹；游戏使用 `assets/photos/` 中的副本。`photo-map.json` 可填写微信图片编号，也可填写完整文件名。运行 `node scripts/prepare-assets.mjs` 后重新构建。

素材整理需本机安装 `cwebp` 和 `jpegtran`。相册使用 1600 像素宽的 WebP，手机缩略图另存为 384 像素宽的 WebP；背景生成长边不超过 2560 像素的桌面版和 1280 像素的手机版 WebP，不放大小图，不裁切构图；原始 JPG 仍保留在本地，构建时不再打包。可单独运行 `node scripts/optimize-photos.mjs` 重新压缩，本地原图不会改动。只更新背景可运行 `node scripts/optimize-backgrounds.mjs`（需要 macOS 的 `sips`、`cwebp` 和 `jpegtran`）；素材清单及内置备用清单会同步生成。GitHub 构建直接使用已整理的素材，无需安装编码器。
