# 照片使用说明

原图保存在本地“图片”文件夹；游戏使用 `assets/photos/` 中的副本。`photo-map.json` 可填写微信图片编号，也可填写完整文件名。运行 `node scripts/prepare-assets.mjs` 后重新构建。
