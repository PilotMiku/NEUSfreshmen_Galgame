# 新生

一个普通同学的东北大学入学故事：军训、早八、回不完的群消息，还有第一次心理班会。

**[在线游玩](https://pilotmiku.github.io/NEUSfreshmen_Galgame/)**

## 本地运行

需要 Node.js 20+，无需安装依赖。

```sh
npm run dev
```

打开 http://127.0.0.1:4173 。

## 操作

点击或空格推进，← 返回上一句，A 自动播放，H 隐藏界面，Esc 返回。

支持单人游玩和班会现场模式。进度自动保存在当前浏览器，也可手动存读档。

人物立绘可后续替换：[添加方法](img_human/README.md)。

`npm test` 检查剧情，`npm run build` 生成静态站点。推送到 main 后自动部署至 GitHub Pages。
