## 网页用的轻量版本

原始 PNG 继续保留。`npm run assets:portraits` 使用 `cwebp` 生成 `optimized/` 中电脑端（最长边 2000）和手机端（最长边 1200）的透明 WebP，同时更新素材清单与 `portrait-variants.json`。当前两套总量分别约为 1.40 MB 和 0.88 MB；网页只加载适合屏幕的一套，并预取下一位班委。

更换 PNG 后再次运行该命令即可。开发预览和构建会检查原图摘要；如果新 PNG 尚未重新优化，会优先使用新原图，不会继续显示旧的 WebP。发布产物只包含被引用的轻量文件，原图仍保存在仓库。

## 网页用的压缩版本

原始 PNG 保留在本目录。`optimized/` 保存带透明通道的桌面版和手机版 WebP，长边上限分别为 2000、1200 像素。重新加入或替换 PNG 后，在安装了 `cwebp` 的电脑上运行：

```sh
npm run assets:portraits
```

该命令同时更新素材清单、内置备用清单和 `portrait-variants.json`。预览和构建会检查原图内容：原图有变化或压缩版本缺失时，先使用新的原图，避免继续显示旧版本。正式发布只包含清单实际引用的图片。班委出场前还会预加载下一位的立绘和替身。
