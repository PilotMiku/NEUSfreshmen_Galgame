建议使用半身或全身立绘，底部对齐，人物四周尽量少留空白。游戏会等比缩放，人物说话时从对话框左侧淡入。

本地放好图片后刷新页面即可。发布时将图片提交到 GitHub，推送 main 后自动构建、上线。

角色映射在 `story.js` 的 `characters` 中；淡入和缺图处理在 `portraits.js`。主角保持第一人称，不显示自己的立绘。

当前班长已接入 `图片/班委/班长.png` 提供的透明全身图，游戏副本为 `img_human/banzhang.png`；保留原图，游戏中以对话框上沿对齐臀部位置，显示头部到臀部的半身构图，下缘延伸到对话框后并逐渐透明。

生活委员、学习委员、文体委员也已接入 `图片/班委/` 的同名透明立绘，分别对应 `shenghuo.png`、`xuewei.png`、`wenti.png`。正式立绘统一按头部到臀部显示、下缘渐隐；各角色的臀部位置通过 `story.js` 中的 `portraitHip` 配置，以适配不同身材比例。

文体委员替身使用 `wenti_stand.png`，仅随文体委员出场，位于本体右上方的后层，透明度 36%，下缘渐隐。来源为 `图片/班委/文体委员替身.png`，通过内置 imagegen 去除白底，保留原角色；完整提示词见 `wenti_stand.prompt.txt`。

六位班委现在均有配对替身。新加入的替身直接使用用户提供的透明 PNG；团支书和组宣也已接入正式立绘。`companionStyle` 分别配置替身高度、右上错位、透明度和旋转，使不同造型按各自比例显示。生活委员的企鹅替身在显示时转正；其余原图保持原样。
